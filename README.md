#The Coffee Waste Reduction Management System is a database-focused project designed to help cafés 
reduce unnecessary coffee product wastage through better inventory tracking, sales monitoring, 
and waste analysis.

#This project was created to demonstrate how database systems can improve operational efficiency in cafés
by monitoring coffee stock, ingredient usage, expired items, and daily waste records.


#The system helps café managers:
-Track coffee inventory
-Monitor product usage
-Reduce ingredient wastage
-Improve stock management
-Analyze waste patterns
-Support sustainable café operations
